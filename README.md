# SIEM Engineer Labs

This repository contains hands-on SIEM engineering labs, detection tuning exercises, log analysis workflows, and security monitoring projects focused on defensive security operations.

Topics Covered:
- SIEM configuration
- Log collection and parsing
- Event correlation
- Detection rule creation
- Alert tuning
- Security monitoring
- SOAR workflows

Tools & Platforms:
- Splunk
- Wazuh
- IBM QRadar
- TheHive
- Sigma

These projects are based on structured cybersecurity training, simulated SOC environments, and independent hands-on learning.
