# Splunk Dashboards

## Objective

Review Splunk dashboard functionality for visualizing security events, monitoring activity, and improving analyst visibility within Search & Reporting.

---

## Dashboard Overview

Splunk dashboards provide visual representations of searchable event data using panels, charts, statistics, and saved searches.

Dashboards help analysts:
- monitor security events
- visualize trends
- track suspicious activity
- improve investigation workflows

---

## Dashboard Workflow

### Access Dashboards

Navigated to:

```text
Search & Reporting → Dashboards
```

---

## Dashboard Creation

Created a new dashboard and configured:
- dashboard title
- permissions
- dashboard panels
- visualization layout

---

## Dashboard Panels

Reviewed dashboard panel functionality.

Panels can display:
- search results
- charts
- tables
- event statistics
- visualizations

Multiple panels can be added to a single dashboard.

---

## Dashboard Use Cases

Dashboards can be created for:
- SOC analysts
- security monitoring
- customer reporting
- operational visibility
- recurring investigations

Dashboards help centralize frequently reviewed information and reusable searches.

Dashboards improve:
