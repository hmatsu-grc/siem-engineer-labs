# Splunk Receiving Configuration

## Objective
Configure Splunk receiving settings to allow forwarders to send data to the indexer.

## Workflow

1. Navigated to:
```text
Settings > Forwarding and Receiving
```

2. Added a new receiving port
3. Configured receiving port:
```text
9997
```

4. Verified forwarder communication and incoming events

---

## Notes

Port 9997 was configured as the receiving port for Splunk Universal Forwarder communication.
