# Splunk User Management

## Objective

Review Splunk user management functionality including role configuration, user account management, role-based access control (RBAC), and password management.

---

## Roles

Splunk includes several default roles used to manage permissions and access visibility.

Roles determine:
- searchable event access
- administrative permissions
- search capabilities
- application visibility
- user privileges

---

## Accessing Role Management

Navigated to:

```text
Settings → Roles
```

Reviewed:
- existing default roles
- role permissions
- role configuration settings

---

## Role Configuration

Reviewed available role management functionality including:
- creating new roles
- modifying role permissions
- controlling searchable event visibility
- limiting or granting application access
- configuring search permissions

---

## User Management

Reviewed Splunk user account management functionality.

Navigated to:

```text
Settings → Users
```

---

## User Accounts

Reviewed:
- existing user accounts
- user role assignments
- account management options

By default, Splunk includes an administrative account:

```text
admin
```

---

## Administrative Account Best Practices

Reviewed security best practices including:
- creating separate administrator accounts
- limiting direct usage of the default `admin` account
- reserving the default administrative account for emergency use

Using separate administrator accounts improves:
- accountability
- auditing visibility
- administrative tracking
