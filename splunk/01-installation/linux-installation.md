# Splunk Installation on Linux

## Objective
Install Splunk Enterprise on Ubuntu Linux.

## Environment
- Ubuntu 22.04
- Splunk Enterprise

## Installation Steps
1. Downloaded Splunk package
2. Extracted installation files
3. Started Splunk service
4. Accepted Splunk license
5. Enabled Splunk at boot

## Verification
Verified Splunk status using:

```bash
/opt/splunk/bin/splunk status
