# Splunk Index Creation

## Objective
Create a custom Splunk index for Windows Event Log ingestion.

## Workflow

1. Navigated to:
```text
Settings > Indexes
```

2. Created a new index:
```text
WinLog_clients
```

3. Assigned forwarded Windows logs to the custom index
4. Verified incoming event visibility

---

## Notes

Custom indexes help separate and organize data sources within Splunk environments.
