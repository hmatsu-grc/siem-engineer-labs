# Splunk

This folder contains Splunk-based security monitoring labs, SPL investigations, dashboard creation exercises, alerting workflows, log ingestion exercises, and Windows Event Log analysis performed within local SOC lab environments.

## Topics Covered

- SPL queries
- Search & Reporting
- Log ingestion
- Universal Forwarder configuration
- Windows Event Log forwarding
- Event correlation
- Alert creation
- Dashboard development
- Security monitoring
- Authentication investigations
- Threat detection workflows
- User and role management
- Splunk health monitoring
